# 🍽️ FoodLoop AI

### ML-Powered Food Waste Prevention & Demand Prediction System

> **FoodLoop AI uses Machine Learning to help cafeterias, hostels, and institutional kitchens predict meal demand and reduce avoidable food overproduction.**

---

## 🌱 About the Project

Food waste is a major sustainability challenge, especially in cafeterias, hostels, canteens, restaurants, and institutional kitchens where food is often prepared using rough estimates of attendance.

**FoodLoop AI** addresses this problem using a data-driven Machine Learning approach.

The system predicts the number of meals likely to be consumed based on factors such as:

- Expected attendance
- Day of the week
- Weekend/weekday
- Exam periods
- Special events
- Temperature
- Menu type

The prediction is then converted into a practical **recommended preparation quantity** with a small safety buffer.
